# Web 控制器

ScreenPlayer 内置了一个可选的局域网 Web 控制器。它直接调用当前 Godot 实例的媒体库和播放器，不需要额外安装或运行 Node/Python 服务。

## 启动与配对

1. 在 ScreenPlayer 的「文件」菜单选择「启动 Web 控制器」。
2. 在播放器电脑显示的对话框中，选择一个局域网地址，并记下 6 位配对码。
3. 手机或电脑连接同一局域网后打开该地址，输入配对码。
4. 如需浏览播放器电脑磁盘上的文件，在「文件」菜单选择「添加 Web 媒体目录…」，只授权你打算分享的目录。授权目录会保存在 ScreenPlayer 设置中。
5. 网页可上传媒体、浏览已授权目录、将媒体加入当前项目，也可在媒体库条目上选择「预览」或「输出」。

停止 Web 控制器后，当前配对令牌和配对码立即失效。重新启动会生成新码；连续输错 6 次后暂停接受配对请求 30 秒。浏览器令牌保存在该浏览器的 localStorage；需要撤销现有设备时，停止后重新启动服务即可。

## 预览质量

网页预览展示播放器当前画面的定时截图，不传送视频流或声音：

- **流畅**：约每 350 毫秒更新一次截图，最高缩放到 960×540。
- **省性能**：约每 1.5 秒更新一次，最高缩放到 480×270。

Godot 主窗口会完成截图缩放和 JPEG 编码；浏览器只拉取已经编码好的图片。截图不会改变播放器的解码、播放或投屏纹理。缩略图按可视区域懒加载，媒体库状态每约 1.2 秒同步一次。

## 访问范围与安全

- 服务默认关闭；仅在用户从桌面应用菜单启动后监听 TCP 8765。
- 配对后才能读取媒体库、缩略图、播放状态、操作播放器、上传或导入文件。
- 文件浏览严格限制在用户从 Godot 文件夹选择器授权的目录中；目录列表只展示 ScreenPlayer 支持的媒体格式。
- 上传文件写入 Godot 用户数据目录下的 user://web_uploads/，随后按现有媒体导入逻辑加入当前项目。
- 当前服务使用 HTTP，配对和后续请求没有 TLS 加密。请只在可信任的私有局域网中使用，不要做路由器端口映射，也不要连接到不可信的公共 Wi-Fi。
- 大文件上传上限为 2 GiB；浏览器通过文件名和扩展名识别媒体类型。播放器电脑仍需安装相应的 Godot/MPV/CEF 媒体依赖。

## 当前界面与边界

页面使用深色三栏布局：左侧按媒体类型筛选，中间搜索、上传和浏览媒体卡片，右侧显示输出端截图与播放控制；媒体卡片的「预览」会加载到 Godot 预览端，「输出」会切换投屏画面。窄屏设备会收起筛选栏，并把预览移到媒体库下方。

Web 控制器操作的是 ScreenPlayer 当前打开的项目。网页不提供项目切换、系统级任意路径浏览、媒体删除、播放列表编辑或实时视频流；网页「上一条/下一条」在播放列表运行时切换列表条目，空闲时按当前项目媒体顺序切换。

出现连接失败时，先确认两个设备位于同一局域网、播放器电脑防火墙允许私人网络访问 TCP 8765、Web 控制器仍在运行。配对码在服务停止或应用退出后失效。
